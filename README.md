# Customer Retention Analysis

## Project Overview

This project analyses customer churn and retention patterns using the Telco Customer Churn dataset.

The objective is to examine customer behaviour, contract types, tenure, payment methods, and internet services to understand customer churn and retention patterns.

## Tools Used

- Microsoft Excel
- Microsoft SQL Server
- Microsoft Power BI
- DAX
- Power Query

## Data Cleaning and Analysis

SQL Server was used to clean and prepare the dataset, check for missing values and duplicate customer records, and analyse customer churn and retention.

The analysis explored overall churn rate, churn by contract type, and churn across tenure groups.

## Dashboard Features

The Power BI dashboard includes the following KPIs and visualisations:

- Total Customers
- Retained Customers
- Churned Customers
- Average Tenure
- Churn Rate
- Retention Rate
- Churn Rate by Tenure
- Customer Count by Contract
- Customer Count by Payment Method
- Customer Distribution by Internet Service
- Churned vs. Retained Customers

## Interactive Features

The dashboard includes slicers for:

- Contract
- Payment Method
- Internet Service

These interactive filters allow users to explore customer retention and churn patterns across different customer categories.

## Dataset

IBM Telco Customer Churn dataset, sourced from Kaggle.
